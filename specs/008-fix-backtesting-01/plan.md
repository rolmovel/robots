## Summary

`01_backtesting.ipynb` fails at cell 12 (`bt.plot()`) due to a Bokeh 3.x API breaking
change: `DatetimeTickFormatter.days` now requires a `str`, but `backtesting 0.3.3`
passes a `list`. The fix wraps `bt.plot()` in a `try/except ValueError` block, which
unblocks cells 13–17. Cell 16 additionally requires replacement of `[placeholder]`
conclusion text with concrete backtest values observed in development.
No logic changes, no dependency changes, and no changes to shared helpers are required.
